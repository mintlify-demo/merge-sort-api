---
title: Quickstart
description: Run the Merge Sort API locally and make your first request.
icon: rocket
---

<Steps>
  <Step title="Get the code and install">
    <CodeGroup>
      ```bash macOS / Linux
      git clone https://github.com/mintlify-demo/merge-sort-api.git
      cd merge-sort-api
      python3 -m venv .venv && source .venv/bin/activate
      pip install -r requirements.txt
      ```

      ```powershell Windows
      git clone https://github.com/mintlify-demo/merge-sort-api.git
      cd merge-sort-api
      python -m venv .venv; .venv\Scripts\Activate.ps1
      pip install -r requirements.txt
      ```
    </CodeGroup>
  </Step>

  <Step title="Start the server">
    ```bash
    uvicorn main:app --reload
    ```

    The API is now running at `http://localhost:8000`.
  </Step>

  <Step title="Sort something">
    <Tabs>
      <Tab title="cURL">
        ```bash
        curl -X POST http://localhost:8000/sort \
          -H "Content-Type: application/json" \
          -d '{"numbers": [5, 2, 9, 1, 5, 6], "order": "asc"}'
        ```
      </Tab>
      <Tab title="Python">
        ```python
        import requests

        r = requests.post(
            "http://localhost:8000/sort",
            json={"numbers": [5, 2, 9, 1, 5, 6], "order": "asc"},
        )
        print(r.json())
        ```
      </Tab>
      <Tab title="JavaScript">
        ```javascript
        const res = await fetch("http://localhost:8000/sort", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ numbers: [5, 2, 9, 1, 5, 6], order: "asc" }),
        });
        console.log(await res.json());
        ```
      </Tab>
    </Tabs>

    You should get back:

    ```json
    { "result": [1, 2, 5, 5, 6, 9], "count": 6, "order": "asc" }
    ```
  </Step>

  <Step title="Watch the merges">
    Call `/sort/steps` with the same body to see each merge. Read [how merge sort works](/merge-sort-api/guides/how-it-works) to understand the output.
  </Step>
</Steps>

<Check>
  You just sorted a list over HTTP. Open `http://localhost:8000/docs` for FastAPI's own interactive docs, or use the playground on any endpoint page here.
</Check>

<AccordionGroup>
  <Accordion title="Do I have to send integers?">
    No. Decimals and negative numbers work too. Anything that isn't a number returns a `422` validation error.
  </Accordion>
  <Accordion title="Is there a size limit?">
    Yes, 1000 numbers per request. A longer list returns a `422`.
  </Accordion>
</AccordionGroup>
