The Merge Sort API is a small FastAPI service with two endpoints. One gives you a sorted list. The other shows you **how** the list got sorted.

<Note>
  This API is a demo. Its code lives in the [merge-sort-api repository](https://github.com/mintlify-demo/merge-sort-api), and these docs live in its `docs/` folder.
</Note>

## At a glance

| Endpoint | Method | Purpose |
| --- | --- | --- |
| `/sort` | `POST` | Sort a list of numbers, ascending or descending |
| `/sort/steps` | `POST` | Same, plus every merge step |

<Tip>
  Every endpoint page has a **Try it** playground. Point it at `http://localhost:8000` while the API is running.
</Tip>
